## How to run
- Install Node.js, or open a browser's Developer Tools and use the Console.
- Run one file at a time with Node.js, for example:

```bash
node Q1_Personalized_Login_Greeting.js
```

Some files use sample values for demonstration. You can edit the variables to test different inputs.
