# Assignment 6 – Async Programming with JavaScript

Student: Dhairya Goswami

## Files
Each question has its own JavaScript file (`Q1` through `Q10`) as required.

## How to run
1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run a file, for example:
   `node Q1_async_coffee_maker.js`
4. Repeat for the other question files.

Q6 uses the Fake Store API and requires internet access. Run it in a modern browser console or Node.js with global `fetch` support.

Several questions intentionally use random failures, so output can vary between runs. Q5 defaults to the nested-callback demonstration; uncomment `runWithAsyncAwait()` and comment out `runWithNestedCallbacks()` to run the cleaner version instead.
