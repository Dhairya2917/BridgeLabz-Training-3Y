# Assignment 7 — DOM Manipulation

This folder contains separate solutions for all 9 questions from the assignment PDF.

## Run
- Open any `.html` file in a browser to test its UI.
- Each question has its own JavaScript file (`q1.js` ... `q9.js`) as requested.
- The HTML files load the matching JavaScript file. Shared styling is in `style.css`.
- No frameworks are used; only HTML, CSS, and core JavaScript (ES6+).
